Jira Quick Search - Support

If you need help with setup or usage, use one of the channels below.

Support channels

  • GitHub Issues: jira-quicksearch-extension/issues
  • Repository: jira-quicksearch-extension

Common checks

  1. Confirm Jira URL, email, and API token are valid.
  2. Ensure host permissions include your Atlassian domain.
  3. Verify network access to Jira and API endpoints.
  4. If using cache-only mode, check cached ticket availability.

What to include in a support request

  • Browser and extension version
  • Exact error message
  • Steps to reproduce
  • Screenshot (if possible)
