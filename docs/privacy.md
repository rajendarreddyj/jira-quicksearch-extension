# Jira Quick Search - Privacy Policy

Jira Quick Search is designed for Jira productivity workflows and stores data locally in the browser for extension functionality.

## Data handling

- Jira settings and app preferences are stored locally.
- Issue cache/history data is stored locally to support offline access and fast retrieval.
- API token fields are excluded from JSON backup exports/imports.

## Data sharing

- The extension does not sell personal data.
- Jira API requests are sent only to configured Jira endpoints and/or project proxy endpoints required for functionality.

## User control

- Users can clear cache/history/settings from the extension settings.
- Users control Jira credentials and can remove them at any time.
