# Support

## Getting Help

- Usage and configuration: see [README.md](README.md)
- Publishing guidance: see [docs/PUBLISHING.md](docs/PUBLISHING.md)
- Questions and feature requests: open an issue at <https://github.com/rajendarreddyj/jira-quicksearch-extension/issues>

## Bug Reports

Please include:

- Steps to reproduce
- Expected vs actual behavior
- Logs or console output (if relevant)
- Environment details (OS, browser version, extension version)

## Security

For security or vulnerability reports, see [SECURITY.md](SECURITY.md). Do not open public issues for security reports.

## Scope

This is an open-source project maintained by the community. Support is provided on a best-effort basis via GitHub Issues.
