# Security Policy

## Supported Versions

We support and patch the latest released version of Jira Quick Search. Pre-release or local development builds are not guaranteed to receive security fixes.

## Reporting a Vulnerability

Please report security issues privately. Do not create a public issue.

- Email: <mailto:rajendarreddyj@gmail.com>
- Include a clear description, reproduction steps, affected version, and potential impact
- If possible, include a minimal reproducible example

We aim to acknowledge receipt within 3 business days and provide an initial assessment within 7 business days.

## Disclosure

We follow responsible disclosure. Once a fix is available, we will publish release notes and coordinate disclosure timing when needed.

## Dependencies

If you discover a vulnerable direct or transitive dependency, please include package name, version, advisory reference, and suggested remediation.
